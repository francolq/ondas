# WAV Utilities

A collection of C programs and Python scripts for working with WAV audio files.

## Overview

This project includes:
- **C programs**: Wave generators (sine, sawtooth, square), wavinfo, wavplot
- **Python scripts**: Wave generators, real-time playback, waveform/spectrogram plotting, BPM detection

## Documentation

See the dedicated README files for each part:
- [README_C.md](README_C.md) - C programs
- [README_PY.md](README_PY.md) - Python scripts

## Quick Start

### C Programs
```bash
make
./sine
```

### Python Scripts
```bash
source ondas/bin/activate
python sine.py
```
